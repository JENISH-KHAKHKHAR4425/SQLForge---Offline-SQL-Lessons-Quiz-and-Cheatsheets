# 📚 SQLForge — Offline SQL Lessons, Quizzes and Cheatsheets

SQLForge is a native Android app that teaches SQL from the ground up — entirely offline. It combines structured lessons, a live SQL playground running on a real embedded SQLite database, topic-wise quizzes, and progress tracking, so learners can go from zero to confident with SQL without needing an internet connection or a server.

## ✨ Features

- 📖 **Structured Lessons** — SELECT, WHERE, ORDER BY, Aggregation, GROUP BY/HAVING, INNER/LEFT JOIN, Subqueries, INSERT/UPDATE/DELETE
- 💻 **Live SQL Playground** — write and run real SQL queries against sample tables (students, courses, enrollments, employees, departments)
- ❓ **Interactive Quiz** — 15 multiple-choice questions with instant explanations
- 📊 **Progress Tracking** — XP, day streaks, and completed lessons
- 🔔 **Sound + Vibration Feedback** — instant feedback on correct/incorrect answers
- 📴 **100% Offline** — no internet connection or account required

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Database:** Android SQLite (SQLiteOpenHelper)
- **UI:** View Binding, Material Components, ConstraintLayout
- **Architecture:** Fragments + Activities, SharedPreferences for local progress storage
